## Slide 13 — Paper 2: LaST-R1 Overview & Motivation
### Layout / レイアウト
- **Section divider style**
- **Title:** Paper 2 — LaST-R1
- **Subtitle:** Reinforcing Robotic Manipulation via Adaptive Physical Latent Reasoning
- **Authors:** Chen, Liu, Yan, Han et al. (CUHK + PKU + Simplexity Robotics, 2026)
- **Project page:** https://siriyep.github.io/last-r1/
- **One-line summary:** *"The first RL post-training framework that jointly optimizes latent reasoning AND action generation."*
- **Three keywords:** *Latent CoT · LAPO (PPO on latents) · Adaptive Reasoning Length*
- **Small visual at bottom right:** mini Fig. 1(a) vs (b) preview — "vanilla VLA RL updates only actions; LaST-R1 updates latents + actions"

### Talking script — English
> Now we move to Paper 2: LaST-R1. The one-line summary is that this is the first reinforcement-learning post-training framework specifically designed for VLA models that *reason before acting*. The three keywords are Latent Chain-of-Thought, LAPO — Latent-to-Action Policy Optimization — and adaptive reasoning length. The motivation is simple: existing VLA-RL methods like SimpleVLA-RL or πRL optimize only the action space and completely bypass internal reasoning. LaST-R1 lets the reward signal directly shape the *reasoning space* too. Note that "latent reasoning" here means deliberation in a high-dimensional continuous feature space, not in natural language tokens — analogous to chain-of-thought in LLMs but tightly coupled with action generation.

### Talking script — 日本語
> 2本目、LaST-R1です。1行で言うと、「行動前に推論する」タイプのVLAモデルに対する、初の強化学習ベースのPost-trainingフレームワークです。キーワードは3つ、Latent Chain-of-Thought、LAPO（Latent-to-Action Policy Optimizationの略）、適応的推論長です。動機はシンプルで、SimpleVLA-RLやπRLなど既存のVLA-RL手法はアクション空間しか最適化せず、内部推論を完全にバイパスしてしまう。LaST-R1は報酬信号を「推論空間そのもの」にも流す点が新しい。ここでの「潜在推論」は自然言語トークンではなく高次元連続特徴空間での思考のことで、LLMのCoTの類似物ですが、アクション生成と密結合している点が違います。

## Slide 14 — LaST-R1 VLA Architecture
### Layout / レイアウト
- **Title:** Architecture: Latent reasoning → parallel action decoding
- **Main visual (left):** Fig. 2(a) — Visual Encoder → LLM Backbone → latent embeddings → `<latent_end>` → action tokens
- **Pipeline annotations:**
  1. Image + instruction → **Qwen3-VL-4B** + SigLIP2-Large encoder
  2. LLM backbone **autoregressively** emits **latent reasoning embeddings**
  3. Terminated by `<latent_end>` token
  4. **Parallel** action decoding (chunk H=8, 56 tokens per chunk)
  5. Value head (4-layer MLP, shared backbone) for advantage estimation
- **Right panel — Hybrid Attention Mask (Fig. 7):**
  - 🔻 Vision+Text+Latent: **causal mask** (autoregressive reasoning)
  - 🔁 Action tokens after `<latent_end>`: **bidirectional mask** (parallel decoding)
- **Caption:** "LLM-style reasoning + parallel action speed, in one model"

### Talking script — English
> The architecture is built on Qwen3-VL-4B with a SigLIP2-Large visual encoder. The backbone first autoregressively produces a sequence of continuous latent reasoning embeddings, terminated by a special `<latent_end>` token. Then continuous actions are produced *in parallel* — single forward pass, chunk size 8, yielding 56 action tokens. A 4-layer MLP value head sharing the backbone is used for advantage estimation. The technical trick that makes this efficient is the hybrid attention mask: causal for the vision-text-latent prefix, bidirectional for the action tokens after `<latent_end>`. So you get the autoregressive reasoning capability of an LLM *and* the parallel decoding speed for actions, in a single model.

### Talking script — 日本語
> アーキテクチャはQwen3-VL-4BにSigLIP2-Largeの視覚エンコーダを載せた構成です。バックボーンはまず連続な「潜在推論埋め込み」を自己回帰的に生成し、`<latent_end>`トークンで終端します。その後、連続アクションを「並列に」、1回のforward passで生成。チャンクサイズ8、計56アクショントークンです。アドバンテージ推定にはバックボーン共有の4層MLPのvalue headを使用。効率を支える技術トリックがハイブリッドアテンションマスクで、Vision+Text+Latent部分は因果(causal)マスクで自己回帰、`<latent_end>`以降のアクショントークンは双方向(bidirectional)マスクで並列、という設計です。LLMの自己回帰的推論能力とアクションの並列デコード速度を、1つのモデルで両立しています。

## Slide 15 — Latent Targets: Why DINOv3 ⟨CLS⟩?
### Layout / レイアウト
- **Title:** What should the latent embeddings target?
- **Main idea (highlighted box):** Latent reasoning targets = **⟨CLS⟩ token of DINOv3** + channel-wise top-k selection (k = 2560 = VLA hidden size)
- **Why this choice?**
  - 🔧 Precomputed **offline** → **zero extra inference cost**
  - 🌍 DINOv3 = SOTA vision foundation model → rich semantic + spatial prior
  - 🎯 Top-k retains most salient channels, matches VLA hidden dim
- **Ablation chart (Fig. 4a) — LIBERO-Spatial SR after RL:**
  - Global Pooling: 96.8%
  - Q-Former: 97.2%
  - Convolution: 98.4%
  - **DINOv3 ⟨CLS⟩ top-k (Ours): 99.8%** ✅

### Talking script — English
> A subtle but important design decision: what should the latent embeddings actually predict? Prior methods use average pooling of the VLA's own visual features or learnable Q-Former queries. The authors instead use the ⟨CLS⟩ token of DINOv3 — a SOTA vision foundation model — and apply top-k channel selection with k = 2560, conveniently matching the VLA's hidden size. The critical engineering benefit is that these targets are precomputed *offline*, so zero extra inference cost. The ablation in Figure 4(a) is decisive: global pooling 96.8%, Q-Former 97.2%, convolution 98.4%, DINOv3 with top-k 99.8% — a 1.4 to 3 point win, validating that leveraging a powerful pretrained foundation model beats learning the latent target from scratch.

### Talking script — 日本語
> 細かいけれど重要な設計判断です。「潜在埋め込みは具体的に何を予測するのか」という問い。先行手法はVLA自身の視覚特徴を平均プーリングしたり、Q-Formerクエリで集約していました。本論文はそれに代えて、最新の視覚基盤モデルDINOv3の⟨CLS⟩トークンを使い、チャネル方向にtop-k(k=2560)で選択。kはVLAの隠れ次元と一致します。エンジニアリング上の最大の利点は、これらのターゲットを「オフラインで事前計算」できる点で、推論時の追加コストがゼロ。図4(a)のablationが決定的で、Global Pooling 96.8%、Q-Former 97.2%、Convolution 98.4%、DINOv3+top-k 99.8%。1.4〜3ポイント差で、強力な事前学習済み基盤モデルを使う方がゼロから潜在ターゲットを学習させるより良いことが示されています。

## Slide 16 — LAPO: PPO on Latents + Actions
### Layout / レイアウト
- **Title:** LAPO — Latent-to-Action Policy Optimization
- **Two equations side by side:**
  - **Action ratio (categorical):**
    $r^a_t(\theta) = \exp(\log \pi_\theta(C_t) - \log \pi_{\theta_{\text{old}}}(C_t))$
  - **Latent ratio (closed form from isotropic Gaussian):**
    $r^z_t(\theta) = \exp\!\left(-\frac{1}{2\sigma^2} \sum_{i=1}^{N_z} \|z^{\text{old}}_{t,i} - z^\theta_{t,i}\|^2 \right)$
- **Derivation hint (small):** old policy mean = $z^{\text{old}}_t$, so $\pi_{\theta_{\text{old}}}(z^{\text{old}}_t)$ = normalization const → cancels
- **Clipped surrogate (joint over latent + action):**
  $\mathcal{L}_{\text{policy}} = -\mathbb{E}_t \sum_{k\in\{z,a\}} \min(r^k_t \hat{A}_t, \text{clip}(r^k_t, 1-\epsilon_{\min}, 1+\epsilon_{\max}) \hat{A}_t)$
- **Total loss:** $\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{action}} + \lambda_1 \mathcal{L}_{\text{latent}} + \lambda_2 \mathcal{L}_{\text{value}} + \lambda_3 \mathcal{L}_{\text{end}}$
- **Intuition box:** "When $\hat{A}_t > 0$ → pull latents toward 'good-reasoning' manifold of successful trajectories"

### Talking script — English
> The core contribution is LAPO — essentially PPO, but treating latent embeddings as implicit decision variables alongside actions. For discrete actions, standard categorical importance ratios. For continuous latents, LAPO approximates the rollout distribution by an isotropic Gaussian centered at the current policy output. The derivation is elegant: the old policy's mean is by definition the sampled latent itself, so the old policy's density at its own sample is just the normalization constant, which cancels with the numerator's normalization. What's left is a clean closed-form: exponential of negative-one-over-two-sigma-squared times the sum of squared latent distances. The clipped surrogate is then formed jointly over both ratios with GAE advantages. Intuitively, when advantage is positive, the optimization pulls the current policy's latent embeddings toward the "good-reasoning" manifold that produced successful trajectories. The optimal loss weights from ablation are λ₁=0.1, λ₂=1, λ₃=0.1.

### Talking script — 日本語
> LaST-R1の中核がLAPOで、PPOのアクションに並んで「潜在埋め込みも暗黙の決定変数」として扱う点が新しい。離散アクションは標準のカテゴリカル重要度比、連続な潜在埋め込みに対しては、ロールアウト分布を「現在のポリシー出力を中心とする等方Gaussian」で近似します。導出が綺麗で、旧ポリシーの平均は定義上「サンプリングされた潜在変数そのもの」なので、旧ポリシーの密度をその自分自身のサンプルで評価すると単に正規化定数になり、分子の正規化と相殺される。結果として、−1/(2σ²)×潜在距離の二乗和、を指数の肩に乗せたきれいな閉形式。Clipped Surrogateを両方の比に対して同時に構成し、アドバンテージはGAEで計算します。直感的には、アドバンテージが正のとき、潜在埋め込みが「成功軌道を生んだ良い推論の多様体」に引き寄せられる。ablationによる最適重みはλ₁=0.1, λ₂=1, λ₃=0.1です。

## Slide 17 — Adaptive Latent CoT: How long to think?
### Layout / レイアウト
- **Title:** Adaptive Latent CoT — variable reasoning length
- **Schematic on the left:**
  - Max length $N_{\max} = 8$
  - $M$ candidate exit positions (best: **M = 4**)
  - **Inference:** emit `<latent_end>` when $p \geq 0.99$
  - **Rollout:** sample length from temperature-controlled categorical
- **Right: sampling equation**
  $p_m = \dfrac{\exp(l_m / \beta)}{\sum_{i=1}^M \exp(l_i / \beta)}, \quad m \sim \text{Categorical}(p_1, \dots, p_M)$
- **Ablation on M (Fig. 4c):**
  - M=1 (fixed): 98.4% | M=2: 99.2% | **M=4: 99.8%** ← best | M=8: 99.0%
- **Insight box:** "Moderate flexibility (M=4) beats both rigidity and over-freedom"

### Talking script — English
> The adaptive latent CoT mechanism. Not every state needs the same deliberation depth — trivial steps should be fast, hard steps should think longer. Within a max length of 8, `<latent_end>` can only be emitted at M predefined positions. At inference, exit as soon as the exit probability exceeds 0.99. During RL rollouts, candidate lengths are sampled from a temperature-controlled categorical, with a separate transition-token loss teaching the model *when* to exit. The ablation in Figure 4(c) is interesting: M=1 fixed-length gives 98.4%, M=4 gives the best 99.8%, but M=8 — letting it exit anywhere — drops back to 99.0%. So too much flexibility hurts; M=4 is the sweet spot between flexibility and optimization stability.

### Talking script — 日本語
> 適応的なLatent CoT機構です。全ての状態が同じ深さの思考を必要とするわけではなくて、簡単な場面はサッと、難しい場面はじっくり考えたい。最大長は8、`<latent_end>`はあらかじめ決まったM個の位置でしか出せない。推論時は終了確率が0.99を超えたら即座に抜けます。RLロールアウト中は候補長を温度付きカテゴリカル分布からサンプリングし、終了トークン専用の損失で「いつ抜けるか」も学習させる。図4(c)のablationが面白くて、M=1（固定長）で98.4%、M=4が最良の99.8%、M=8（どこでも抜けられる）にすると99.0%まで戻る。柔軟性を与えすぎても駄目で、M=4が柔軟性と最適化安定性のスイートスポットです。

## Slide 20 — What did the Policy Learn? & Takeaways

- **Three sub-panels side by side:**

  **(1) Reasoning length shifts (Fig. 9):**
  - Before RL: uniform over {2, 4, 6, 8}
  - After LAPO: sharp peaks at **2 and 4** → learns to think *short*

  **(2) Execution steps drop below expert (Fig. 10):**
  - Spatial: Expert 109 / Before-RL 153 / **After-RL 102** ✅
  - Object: 137 / 181 / **124** ✅
  - Goal: 106 / 176 / **104** ✅

  **(3) Action-to-Vision attention (Fig. 16, Grad-CAM):**
  - Action-Only: diffuse, lags gripper
  - LaST-R1 + LAPO: focused, anticipates target, dynamically shifts object → target

- **Bottom (highlighted takeaway box):**
  *"RL on latents = test-time scaling for robotics — shorter thinking, faster execution, better attention, all learned from reward."*

### Talking script — English
> Three analyses showing what the optimized policy actually learned. First, the reasoning-length distribution shifts dramatically after LAPO — before RL it's roughly uniform over 2, 4, 6, 8 (because warm-up samples uniformly), but after LAPO it peaks sharply at lengths 2 and 4. The policy learns to think *short*. Second, actual execution episode lengths on Spatial, Object, and Goal drop *below* the scripted expert demonstrations — on Spatial the expert takes 109 steps, pre-RL needs 153 because it wanders, and post-RL takes just 102. Third, Grad-CAM attention maps show LaST-R1 + LAPO develops focused, goal-directed visual attention that dynamically shifts from the manipulated object to the target. The takeaway: RL on latents is effectively *test-time scaling for robotics* — adaptive thinking budgets, shorter execution, better attention, all learned automatically from reward.

### Talking script — 日本語
> 最適化されたポリシーが何を学んだか、3つの分析です。1つ目、推論長の分布がLAPO後に劇的に変化。RL前は長さ2, 4, 6, 8にほぼ一様分布（warm-upの一様サンプリングのため）が、LAPO後は長さ2と4にシャープなピーク。「短く考える」ことを学習しています。2つ目、実行ステップ数がSpatial、Object、Goalスイートでエキスパート実演を「下回る」。Spatialではエキスパート109、RL前153（彷徨うので増える）、RL後102と、エキスパートに勝っている。3つ目、Grad-CAMによるattention mapで、LaST-R1+LAPOは焦点が定まった目標指向的な注意を持ち、操作物体→目標へと動的にシフトする。総括すると、潜在空間でのRLは「ロボティクスのtest-time scaling」として機能していて、適応的な思考予算、短い実行、優れた注意、すべてが報酬から自動で学ばれているわけです。
